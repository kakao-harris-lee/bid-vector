# G-2 Parallel Ops Workflow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the next five roadmap priorities as safe local/CLI workflows that prepare, validate, and package G-2 evidence without performing unapproved production writes.

**Architecture:** Keep the existing read-only and approval-first boundary. Each lane owns a disjoint script/test pair, and the controller owns docs after worker integration. Live API, production DB, Telegram, and synthetic writes remain operator-controlled and are represented as evidence plans, approval records, and local review bundles.

**Tech Stack:** Python CLI scripts, pytest, JSON evidence files under `reports/g2-evidence/`, existing FastAPI endpoints and runbook contracts.

---

## Write Ownership

- Lane 1, evidence accumulation: `scripts/collect_g2_evidence.py`, `tests/test_g2_evidence_collection.py`.
- Lane 2, blocking gaps: `scripts/g2_blocking_gap_register.py`, `tests/test_g2_blocking_gap_register.py`.
- Lane 3, sample-gap execution evidence: `scripts/run_g2_synthetic_evidence.py`, `tests/test_run_g2_synthetic_evidence.py`.
- Lane 4, notification targets: `scripts/verify_g2_notification_targets.py`, `tests/test_verify_g2_notification_targets.py`.
- Lane 5, exit readiness: `scripts/check_g2_exit_readiness.py`, `tests/test_check_g2_exit_readiness.py`.
- Controller docs only after workers finish: `docs/operations/g2-evidence-runbook.md`, `README.md`.

Workers must not edit files outside their ownership without returning `NEEDS_CONTEXT`.

## Lane 1: G-2 Evidence Accumulation

Roadmap item: N-day evidence for 3+ virtual operators.

## Lane 2: G-2 Blocking Gap Register

- [x] Create failing tests in `tests/test_g2_blocking_gap_register.py`.

## Lane 3: G-1 Sample-Gap Execution Evidence

- [x] Add failing tests in `tests/test_run_g2_synthetic_evidence.py` for `--evidence-out`.

## Lane 4: G-2 Notification Target Verification
