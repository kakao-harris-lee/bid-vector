# floor 앵커 base 정합 가설 검증 — 불지지 판정 (2026-07-27)

`docs/operations/real-bid-195-revalidation.md`(2026-07-25)가 고정한 다음 가설 —
**"하드 법정 floor 앵커를 `0.88×기초금액`에서 `0.88×E[예정가]`로 정합하면 과추천이
줄어든다"** — 를 floor-bound 실측 코퍼스로 검증한 결과다. 읽기 전용 분석이며
predictor·guardrail 코드는 변경하지 않았다.

## 결론

**가설 불지지 — 앵커 하향 재캘리브레이션은 하지 않는다.**

1. 전제였던 "사정률(예정가/기초)<1이 일반적"이 실측에서 약하다: 코어 532쌍의 실측
   사정률은 평균 **0.9974**(중앙값 0.9977, p5 0.9838 ~ p95 1.0100)로 1에 밀착하고,
   **37.6%는 1보다 크다**(예정가>기초금액). 현행 앵커의 평균 초과는 기초금액 기준
   **+24bp**에 불과하며 방향도 양쪽으로 갈린다.
2. E[사정률] 전환의 효과: |잔차| 59.9→57.6bp(−2.3bp, 무의미)인 반면 **실격 위험
   (제안 floor<실현 floor)은 37.6%→52.1%로 악화**된다. 공고별 사정률은 복수예비가
   추첨으로 정해지는 ±1%p 랜덤이라 E의 평균 이동(−0.26%p)을 압도한다. 발주처별
   E(LOO)도 전역과 동일한 결과 — 차별력이 없다.
3. 낙하-홀드아웃 게이트: floor를 "실격 없는 안전 하한"으로 쓰려면 앵커를 내리는 게
   아니라 **올려야** 한다(사정률 p95≈1.010 앵커 시 실격 5.1%, p99≈1.015 시 1.1%).
   "정확한 floor"와 "안전한 floor"는 추첨 랜덤 때문에 양립하지 않는다(완전 예지
   오라클만 잔차 0).
4. 실투찰 2건(`R26BK01627948`/`R26BK01628093`) 재현: 낙찰자는 실현 하한
   **+0.1bp/+1.9bp**에 착지했다. 제안 앵커를 썼어도 추천은 낙찰가 위(+0.11/+0.45%p)에
   남는다 — 패인은 앵커 정밀도가 아니라 **사정률 추첨을 맞히는 게임**(축소 불가능한
   랜덤)이다.

**남는 개선 축은 앵커가 아니라 recommended candidate selector다**: floor-bound
공고에서 낙찰은 하한 위 중앙값 +50bp 근처(공사 +55.5bp, 용역 +13.3bp)에 밀집하므로,
"하한 위 어디에 설지"의 선택 정책이 실질 레버다(로드맵 "추천 품질 후속" 4번 연결).

## 방법

- 코퍼스 사다리(침묵 제외 없음): 원본 조인 1,031쌍(`award_floor_rate`+`winning_rate`+
  예비가 보유) → 금액 유효 1,028 → 게시 하한 개연 1,024 → 적용 범위 applicable 974
  (비국가 15·uncertain 34·산림 7 제외) → basis clean 714 → 추첨 전량 보유 709 →
  예비가-기초 정합 532 = **코어**.
- 기존 품질 인프라 재사용: basis 태깅(#199), 적용 범위·게시 하한 개연성(#274/#296),
  rate 독립성(#288). 실측 사정률 = 추첨 4개 예비가 평균/기초금액.
- 앵커 변형 비교: 현행(E=1) / 전역·발주처 E[사정률](LOO) / 보수 p95·p99 / 오라클.
  각 변형의 |잔차|·실격률·필요 안전 마진(p95/p99)을 산출.

## 한계 (정직 명세 §2)

- 코퍼스는 `award_floor_rate` 적재 공고에 한정되고 공고일이 2026-07-02~07-20에 몰려
  있다(era 비교 불성립, 게시 하한 없는 협상·수의 유형 미포함).
- 15개 예비가 평균은 실현 예정가(추첨 4개 평균)의 근사다(비율 p5 0.989~p95 1.012).
- 발주처별 E는 표본 부족으로 전역과 사실상 동일 — 발주처 차별력 부재는 "없다"가 아니라
  "이 표본으로는 못 본다"로 읽는다.
- 재캘리브레이션 실행 여부 결정은 운영자 소관이다(이 문서는 증거와 권고까지).
